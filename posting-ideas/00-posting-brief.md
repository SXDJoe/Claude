# Posting brief

Source: `Posting Ideas.pdf`, page 1.
Scope: governs every topic file in this folder.

## The rules on the page

Posts start from what went wrong. The angle is close to a complaint.

Topics are sequenced so they tell one story about where Joe helps. A post is not a standalone item.

Each post must be unconventional, thought provoking, an unpopular opinion, and full of value for the reader at the same time.

The test of a post is a response or an interaction, not a view count.

## Evaluation

The four requirements pull against each other and the page does not say which one wins. Unconventional and unpopular push toward provocation. Full of value pushes toward teaching. A post that tries to do both in equal measure usually does neither: the provocation gets softened to stay useful, and the teaching gets thinned to stay sharp.

Set the order: unpopular opinion first, value second, and the value is what makes the opinion survivable. The opinion opens, the mechanism pays the reader for staying.

The bigger risk is the complaint angle. Complaint reads as status-lowering when the complainer has no fix in the same post. It reads as authority when the fix follows immediately. The rule should be: name the failure in the first two lines, name the mechanism that caused it by the middle, and close on what you would have done. Never post the complaint alone.

"Sequenced so they tell a story" is the instruction with the most value and the least support. There is no sequence on these pages, only a list. A sequence is proposed in `00-index.md`.

## Open decision

The complaint angle needs a source. Complaints drawn from named client work are the strongest and the least publishable. Complaints drawn from generic market observation are publishable and forgettable. Decide which anonymisation standard applies before the first post, not after a client recognises themselves.
